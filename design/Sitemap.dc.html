Azərbaycan Xəbər Portalı — Sayt Strukturu (Sitemap)

Stack: Django + HTML/CSS/JS (без React) · Dil: yalnız Azərbaycan · İki hissə: Publik sayt + CMS (Admin panel)

0. Sistem Arxitekturası (yüksək səviyyə)

CMS / Admin Panel
Django Admin (custom) + templates
Redaktor, Jurnalist, Moderator, Admin
──write──▶
Verilənlər bazası
PostgreSQL (Django ORM)
+ Redis (cache, opsional)
──read──▶
Publik Sayt
Django views + HTML/CSS/JS
Server-side render, SEO-friendly
Qeyd: CMS heç vaxt birbaşa publik şablonlara yazmır — bütün əlaqə DB vasitəsilə. Publik sayt yalnız "published" statuslu məzmunu oxuyur.

1. Publik Hissə — Sitemap

Bütün URL nümunələri şərtidir. Struktur BBC / Reuters / Bloomberg / CNN best-practice-lərinə əsaslanır: kateqoriya → məqalə iyerarxiyası, ayrıca video/foto bölmələri, uzun-format analitika, tag-based kəşfiyyat.
Ana səhifə  (/)
├── Breaking news lenti (homepage-də üst blok, real-time)
├── Xəbərlər  (/xeberler/)
│   ├── Kateqoriya səhifəsi  (/xeberler/<kateqoriya>/)
│   │   └── Məqalə səhifəsi  (/xeberler/<kateqoriya>/<slug>/)
│   │       ├── Şərhlər bloku
│   │       ├── "Oxşar xəbərlər" bloku
│   │       ├── Müəllif kartı → Müəllif profilinə keçid
│   │       └── Paylaş / Çap et / PDF
│   ├── Siyasət · İqtisadiyyat · Dünya · Region
│   ├── Cəmiyyət · Mədəniyyət · İdman
│   └── Texnologiya · Sağlamlıq · Elm
├── Analitika / Rəy  (/analitika/)
│   └── Analitik məqalə səhifəsi (uzun format, imzalı müəllif)
├── Xüsusi Layihələr / Longread  (/layiheler/)
│   └── Layihə səhifəsi (custom scroll-şablon, multimedia)
├── Video  (/video/)
│   ├── Video kateqoriyaları
│   └── Video izləmə səhifəsi (player + transkript)
├── Foto Qalereya  (/foto/)
│   └── Qalereya səhifəsi (lightbox)
├── Mövzular / Etiketlər  (/movzu/<tag>/)          — bir mövzu üzrə bütün format (xəbər+video+analitika)
├── Müəllif Profili  (/muellif/<slug>/)            — bio + bütün yazıları
├── Axtarış Nəticələri  (/axtaris/?q=)
├── Arxiv  (/arxiv/<il>/<ay>/<gun>/)         — tarix üzrə göz atma
├── İstifadəçi Hesabı  (opsional membership qatı)
│   ├── Giriş / Qeydiyyat  (/hesab/giris/, /hesab/qeydiyyat/)
│   ├── Seçilmiş xəbərlər  (/hesab/secilmisler/)
│   └── Bildiriş tənzimləmələri
├── Newsletter Abunəliyi  (footer-də inline form + /abunelik/)
├── Haqqımızda  (/haqqimizda/)
├── Əlaqə  (/elaqe/)
├── Reklam  (/reklam/)                                — "Advertise with us"
├── Hüquqi Səhifələr
│   ├── Məxfilik Siyasəti  (/mexfilik/)
│   ├── İstifadə Şərtləri  (/sertler/)
│   └── Redaksiya Siyasəti / Düzəlişlər  (/redaksiya-siyaseti/)
├── RSS Lentləri  (/rss/, /rss/<kateqoriya>/)
└── 404 / Xəta Səhifəsi

2. CMS / Admin Panel — Sitemap

Rol-əsaslı giriş: Admin (tam giriş) · Redaktor (nəşr/rədd) · Jurnalist (yalnız öz məzmunu, draft) · Moderator (yalnız şərhlər).
Giriş  (/admin/login/)
└── Dashboard  (/admin/)                        — statistika, son fəaliyyət, tapşırıqlar, xəbərdarlıqlar
    ├── Məzmun İdarəetməsi
    │   ├── Xəbərlər
    │   │   ├── Bütün xəbərlər  — siyahı + filtr (status: draft / gözləyir / dərc olunub)
    │   │   ├── Yeni xəbər  — WYSIWYG redaktor, SEO bloku, media, planlaşdırılmış nəşr
    │   │   └── Xəbər redaktəsi  — versiya tarixçəsi, "kim nə vaxt dəyişdi"
    │   ├── Kateqoriyalar  — CRUD, sıralama, menyu strukturu
    │   ├── Etiketlər  — CRUD
    │   ├── Media Kitabxanası  — şəkil/video yükləmə, crop, alt-text (SEO)
    │   ├── Video İdarəetməsi
    │   ├── Xüsusi Layihələr / Longread Builder
    │   └── Breaking News / Ticker İdarəetməsi  — homepage üst zolağı
    ├── Baş Səhifə Düzülüşü  — bloklərin əl ilə düzülməsi (manual curation)
    ├── Şərhlər Moderasiyası  — təsdiq / rədd / spam, istifadəçi bloklama
    ├── İstifadəçilər və Rollar
    │   ├── Jurnalistlər / Müəlliflər  — profil, bio, imza
    │   ├── Redaktorlar
    │   ├── Moderatorlar
    │   └── Rol və İcazələr  — permission matrix
    ├── Abunəçilər / Newsletter İdarəetməsi  — siyahı, kampaniya göndərişi
    ├── Reklam İdarəetməsi  — banner yerləşdirmə, kampaniya, klik statistikası
    ├── SEO və Analitika
    │   ├── Meta teqlər, sitemap.xml generasiyası
    │   └── Trafik statistikası (GA inteqrasiyası)
    ├── Sayt Tənzimləmələri
    │   ├── Ümumi  — loqo, sayt adı, əlaqə məlumatı
    │   ├── Menyu İdarəetməsi
    │   └── Footer Linkləri
    ├── Bildirişlər  — push/email tənzimləmələri
    └── Fəaliyyət Jurnalı (Audit Log)  — kim, nə vaxt, nə etdi

4. User Flow — CMS (Jurnalist → Redaktor → Nəşr)

Redaksiya prosesi review addımı ilə: Jurnalist yazır, Redaktor təsdiqləyir, sonra dərc olunur. Ayrıca Moderator qolu şərhlər üçün.
Giriş (login)
     │
     ▼
Rol yoxlanışı  (Admin / Redaktor / Jurnalist / Moderator)
     │
     ▼
Dashboard
     │
     ▼
Xəbərlər bölməsi  →  "Yeni xəbər" düyməsi
     │
     ▼
Redaktor (WYSIWYG + media + SEO bloku + kateqoriya/etiket)
     │
     ▼
Saxla (Draft)
     │
     ▼
Jurnalist → "Redaktora göndər" (review sorğusu)
     │
     ▼
Redaktor baxışı ──── Rədd (qeyd ilə) ──▶ geri Jurnalistə (Draft-a düzəliş)
     │
     ▼ Təsdiq
Nəşr planlaşdırma  (indi dərc et / gələcək tarixə planla)
     │
     ▼
Dərc olunur  (status: published)
     │
     ▼
Publik saytda avtomatik görünür  →  Dashboard statistikası yenilənir
     │
     ▼
Post-publish: səhv aşkarlansa → Redaktə → "Fəaliyyət jurnalı"na qeyd olunur


Paralel qol — Moderator:
Giriş → Dashboard → Şərhlər Moderasiyası → Təsdiq / Rədd / Spam olaraq işarələ
Növbəti addım: bu strukturu təsdiqlə → sonra wireframe (aşağı fidelity) səhifə düzülüşlərinə keçə bilərik, dizayn olmadan.
